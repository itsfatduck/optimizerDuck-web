# Download Issues

> The download won't start or gets blocked

If clicking the download button does not start the download, try the following solutions.

## Try the manual download link

When the download dialog appears, look for the **manual download link** to bypass any automatic redirect and start the download directly.

## Check your browser

Your browser may be blocking the download. Look for:

- A blocked download notification in the browser's **download bar**
- A popup or notification in the **top-right corner** of the browser
- A shield icon in the **address bar** (especially in Chrome and Edge)
- A **SmartScreen** or **Safe Browsing** warning page

If you see a blocked download notification, click **"Keep"**, **"Allow"**, or **"Download anyway"** to proceed.

### Browser-specific tips

**Google Chrome:** Go to **Settings** → **Privacy and security** → **Security** → disable **Safe Browsing** temporarily, or click the download arrow in the top-right and select **Keep**.

**Microsoft Edge:** Click the **three dots** menu → **Downloads** → find optimizerDuck and click **Keep** or **Allow**.

**Mozilla Firefox:** Click the **download arrow** in the toolbar → right-click the blocked file → **Allow download**.

## Try a different browser

If the issue persists, try downloading with a different browser:

- [Google Chrome](https://www.google.com/chrome/)
- [Mozilla Firefox](https://www.mozilla.org/firefox/)
- [Microsoft Edge](https://www.microsoft.com/edge)

## Download from GitHub directly

You can always download optimizerDuck directly from the [GitHub Releases page](https://github.com/itsfatduck/optimizerDuck/releases). Look for the `.exe` file in the latest release assets.

## Check your internet connection

Make sure you have a stable internet connection. Try:

1. Opening other websites to verify connectivity
2. Restarting your router
3. Disabling VPN or proxy if you are using one
4. Temporarily disabling your firewall to rule out interference

## Clear your browser cache

Corrupted cached data can sometimes interfere with downloads:

1. Open your browser's **Settings**
2. Find **Privacy & Security** → **Clear browsing data**
3. Select **Cached images and files** and clear them
4. Try the download again

## I found a bug / want to request a feature
