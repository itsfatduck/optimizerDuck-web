# App Running Slowly

> optimizerDuck is unresponsive or slow

If optimizerDuck takes a long time to load or respond, try the following.

## Close unnecessary programs

Other applications may be consuming system resources. Close any programs you are not actively using, especially:

- Web browsers with many tabs open (these consume significant RAM)
- Games or resource-intensive applications
- Other system tools running in the background

## Check your disk space

If your system drive (C:) is nearly full, your entire system (including optimizerDuck) may become sluggish:

1. Open **File Explorer**
2. Right-click your **C: drive** → **Properties**
3. If free space is below **1 GB**, free up some space

### Free up disk space

- Use optimizerDuck's built-in [Disk Cleanup](/docs/features/disk-cleanup) tool to remove temporary files and cache
- Empty the **Recycle Bin**
- Uninstall programs you no longer use
- Run Windows **Disk Cleanup** by searching for it in the Start menu

## Restart your computer

A simple restart can resolve many performance issues by clearing temporary files and freeing up memory. It also stops any lingering background processes that may be interfering.

## Disable unnecessary startup programs

Too many startup programs can slow down your system. You can use optimizerDuck's built-in [Startup Manager](/docs/features/startup-manager) to manage which programs run at startup. No need for third-party tools.

## Try running as Administrator

Some performance issues are caused by permission restrictions. Try:

1. Right-click **optimizerDuck**
2. Select **Run as administrator**

This ensures the app has full access to system resources and can apply optimizations without delays.

## Re-download the app

In rare cases, the executable file may have become corrupted during the initial download:

1. **Delete** the current optimizerDuck `.exe` file
2. **Re-download** the latest version from the [Download page](/docs/download)
3. Try running the fresh copy
